# Dataset v1 · used in episode 01

The dataset shown in [01 · What Is a Knowledge Graph?](../../episodes/01-what-is-a-knowledge-graph/). Kept unchanged so the episode still reproduces exactly.

A fictional supplier, **Brightline Supply Co.**, and four customers: Acme, Northpeak, Orbis Foods and Veltra.

| File | What's inside |
|---|---|
| [`01_support_tickets.md`](01_support_tickets.md) | 6 support tickets: late deliveries, damaged goods, billing, account changes |
| [`02_customer_contracts.md`](02_customer_contracts.md) | 3 customer contracts with delivery SLAs and remedies, plus one customer with no contract |
| [`03_refund_policy.md`](03_refund_policy.md) | The refund policy the contracts point to (sections 1–6) |
| [`questions.md`](questions.md) | Test questions with expected answers and hop counts |

Starting from episode 02, the series uses the larger [dataset v2](../02-knowledge-graph-vs-regular-rag/).
